# ComputerCraft Scripts

This repository is a collection of general scripts designed for use in Minecraft's ComputerCraft Mod.

The scripts contained herein are intended to provide useful automation and functionality within the ComputerCraft environment.

## Usage
Scripts can be run directly within the ComputerCraft mod environment.

## Documentation
For concrete details and official documentation regarding ComputerCraft, please refer to the official ComputerCraft Mod documentation and community resources, specifically: https://computercraft.info/ and https://tweaked.cc

## Contents
- `checkfuel.lua`: Script for checking and refueling fuel.
- `patroller.lua`: Script implementing a patrol routine.
